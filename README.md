A website developed for a beauty studio and training centre in Lagos, Nigeria.

- Built with React, TypeScript and Tailwind CSS.

- Designed for mobile and desktop devices.

**Live Website:** https://pwesh-beauty-hub.netlify.app/

**GitHub Repository:** https://github.com/Damilola-Dev1/pwesh-beauty-hub

### 3. Cedars School Management System

An independently developed school management application designed to support administrative activities within a school.

- Covers student records, fee payment tracking, attendance and academic results.

**Project Status:** Under development and security review.

### 4. Expense Tracker

A personal expense management application built to practise JavaScript and application development fundamentals.

- Built with HTML, CSS and Vanilla JavaScript.
- Supports adding, editing and deleting expenses.
- Includes date filtering, form validation and localStorage persistence.
- Supports recording expenses in Naira and Dollars.

A weather application that provides current weather information for the capital cities of Nigeria's 36 states and the Federal Capital Territory.
